 GitHub Profile Analyzer 

A simple web application that analyzes GitHub profiles and displays useful information such as repositories, followers, following, stars, and programming languages.

##  Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript
* GitHub REST API

No frameworks or libraries used.

 Features

* Search GitHub users by username
* View profile information
* Display repository statistics
* Show followers, following, and stars
* Display programming languages
* Responsive and simple UI
*
 How to Run

Clone the repository and open `index.html` in your browser.

git clone https://github.com/YOUR-USERNAME/github-profile-analyzer.git
